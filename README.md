# Dental Practice Patient Communication Bot

Telegram bot for dental practices automating patient communication and appointment management. Sends appointment reminders 48h and 2h before visits, handles cancellation and reschedule requests, delivers post-treatment care instructions, collects satisfaction ratings after appointments, and sends recall notifications for 6-month checkups. Practice managers get a daily digest of bookings and cancellations. Supports multi-dentist practices with calendar sync. Zero coding setup via admin configuration panel.

## Setup
1. Set `TELEGRAM_BOT_TOKEN` in `.env`
2. `pip install -r requirements.txt`
3. `python main.py`
